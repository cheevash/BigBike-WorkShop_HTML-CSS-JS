# 🏍️ APEX MOTORS | Premier Superbike & Motorsport Gear Platform

A cutting-edge, high-octane Superbike Showroom and Motorsport E-commerce web application built with modern HTML5, Vanilla CSS3 (Custom Design System), and Vanilla JavaScript ES6+.

![APEX MOTORS Banner](image/slide.png)

---

## ⚡ Key Highlights & Features

### 🏁 1. Modern Luxury Racing Aesthetic
- **Aggressive & Sleek Dark UI**: Carbon & Obsidian surfaces with glowing Acid Lime / Emerald accents (`#00E676`).
- **Typography Hierarchy**: Powered by Google Fonts `Syne` (high-impact automotive headers) and `Plus Jakarta Sans` (ultra-crisp body readability).
- **Fluid Responsiveness**: Tailored layout matching desktop, tablet, and mobile screens.

### 🛒 2. Full E-Commerce Experience
- **Interactive Slide-Out Cart Drawer**:
  - Live quantity adjustment (`+` / `-`), instant item removal, and subtotal calculation.
  - Promo code redemption engine (`APEX10` for 10% off, `RACE20` for 20% off).
  - Simulated instant checkout with celebratory **Canvas Confetti** animation and order confirmation receipt modal.
  - Persistent state saved to browser `localStorage`.
- **Quick View Modal**: In-depth technical specs, detailed product description, dynamic rating stars, quantity counter, and "Add to Cart" action.
- **Wishlist Engine**: Real-time heart toggles with navbar badge counter and instant wishlist filtering.
- **Multi-Currency Converter**: Toggle seamlessly between **USD ($)**, **THB (฿)**, and **EUR (€)** with automatic real-time rate conversions.

### 🏍️ 3. Superbike Showroom & Interactive Tools
- **2026 Model Launch Countdown**: Real-time ticking launch countdown timer (Days, Hours, Minutes, Seconds).
- **Featured Superbike Showroom Slider**: Powered by Swiper.js with power, torque, top speed, and displacement matrix.
- **Interactive Financing / EMI Calculator**: Real-time slider controls for MSRP, Down Payment %, Loan Term (Months), and APR % with live installment recalculation.
- **VIP Test Ride Booking System**: Full booking modal with motorcycle selector, dealership showroom branches, date selection, and instant confirmation toast.
- **Filterable & Searchable Store**: Instant filter tabs (Helmets, Boots, Gloves, Suits, Exhausts, Performance Brakes/Forks) with live search.
- **Verified Rider Reviews**: Real rider feedback with star ratings and photos.
- **Toast Notification Engine**: Floating notifications for all user actions.

---

## 🛠️ Tech Stack & Dependencies
- **Core**: HTML5, Vanilla CSS3, Vanilla JavaScript (ES6+)
- **Icons**: FontAwesome 6 Pro/Free
- **Carousels**: Swiper.js v11
- **Animations & Effects**: Canvas Confetti

---

## 🚀 How to Run Locally
Simply open `index.html` in any modern web browser or serve via Live Server:
```bash
# Using Python
python -m http.server 3000

# Or using Node / npx serve
npx serve .
```
Then visit `http://localhost:3000` in your browser.
